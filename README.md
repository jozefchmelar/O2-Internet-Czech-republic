## Do NOT accept O2 router.
- O2 will try to tell you need it. You probably don't.
- Under no circumstances allow the technician to open, unwrap the o2 router.
- Tell him to NOT install it. The technician is not allowed to take it back.
- DO NOT UNWRAP IT !
- Take it to the O2 store - they accepted mine on Florenc.
- Make sure they will not charge you for it.

## Buy a different router 
Routers that I have tested : 
- TP-Link Archer C6 V3.2 https://www.alza.cz/tp-link-archer-c6-v3-2-d6742355.htm  
- TP-Link Archer AX17 AX1500 Wi-Fi 6 https://www.alza.cz/tp-link-archer-ax17-ax1500-wi-fi-6-d12555413.htm

You probably need a router which supports PPPoE. 

I'd recommend AGAINST buying TP-Link routers due to security https://www.nsa.gov/Press-Room/Press-Releases-Statements/Press-Release-View/Article/4453919/nsa-supports-fbi-in-highlighting-russian-gru-threats-against-routers/



## Setup the router 
- Connect to the router via wifi/ethernet. Go to `192.168.0.1` 
> note : the address may vary on the router. Usually it's `192.168.0.1` or `192.168.1.1`   or `192.168.1.2`  or smth like that.
- Connection type  : PPPoE
- username/password :  O2/O2  (capital letters)
- Internet VLAN ID : 848
